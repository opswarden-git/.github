# OpsWarden

OpsWarden is an open-source incident response platform for small teams who need
real-time coordination without heavyweight enterprise tooling.

The current alpha focuses on:

- incident lifecycle management with live timelines
- release coordination with automatic incident-based blocking
- team roles, moderation, presence, and private messages
- desktop notifications through a Tauri shell
- automation hooks for CI failures and external integrations

The graded product currently lives at
[RomeoCavazza/opswarden](https://github.com/RomeoCavazza/opswarden).
This organization is being prepared as the long-term home for the OpsWarden
ecosystem: app, ops, docs, and website.

More structure is coming after the v1.0 packaging and jury delivery pass.
